# Guide d'utilisation : Sections de contenu des projets

## 📝 Vue d'ensemble

Le système de **sections de contenu** vous permet de créer des pages de projets riches et variées, adaptées à chaque type de projet.

## 🎨 Types de mise en page disponibles

### 1. **📝 Texte seul**
Idéal pour : Explications, contexte, descriptions détaillées

**Affichage :**
```
Titre de la section
Sous-titre (optionnel)
━━━━━━━━━━━━━━━━
Contenu texte riche...
```

### 2. **🖼️ ← Image à gauche + Texte**
Idéal pour : Présenter un lieu, une personne, un élément spécifique

**Affichage :**
```
┌─────────────┐  Titre de la section
│             │  Sous-titre
│    IMAGE    │  ━━━━━━━━━━━━━━━━
│             │  Contenu texte...
└─────────────┘
Légende
```

### 3. **🖼️ Texte + Image à droite →**
Même chose que #2, mais inversé

**Affichage :**
```
Titre de la section  ┌─────────────┐
Sous-titre           │             │
━━━━━━━━━━━━━━━━    │    IMAGE    │
Contenu texte...     │             │
                     └─────────────┘
                     Légende
```

### 4. **🖼️ Image en haut, texte en bas**
Idéal pour : Mettre en valeur une grande photo, un moment important

**Affichage :**
```
┌─────────────────────────────┐
│                             │
│         IMAGE               │
│                             │
└─────────────────────────────┘
Légende

Titre de la section
Sous-titre
━━━━━━━━━━━━━━━━
Contenu texte...
```

### 5. **💬 Citation / Témoignage**
Idéal pour : Témoignages, citations inspirantes

**Affichage :**
```
┃  Titre (optionnel)
┃  
┃  "Contenu de la citation..."
┃  
┃  — Sous-titre (auteur, source)
```

## 🚀 Comment utiliser dans TinaCMS

### Étape 1 : Créer une section
1. Allez dans **Projets** dans TinaCMS
2. Ouvrez un projet existant ou créez-en un nouveau
3. Trouvez **"Sections de contenu du projet"**
4. Cliquez sur **"+ Ajouter une section"**

### Étape 2 : Configurer la section
1. **Titre** : Le titre principal de la section (obligatoire)
2. **Sous-titre** : Un texte d'introduction (optionnel)
3. **Type de mise en page** : Choisissez parmi les 5 options
4. **Contenu** : Le texte principal (rich text)
5. **Image** : Ajoutez une image si nécessaire
6. **Légende** : Description de l'image (optionnel)

### Étape 3 : Organiser les sections
- Drag & drop pour réorganiser l'ordre
- Dupliquer une section
- Supprimer une section

## 💡 Exemples d'utilisation

### Projet "Recherche de fonds"
```
Section 1 : Texte seul
  Titre: "Contexte et motivation"
  Contenu: Explication du projet...

Section 2 : Image à gauche + Texte
  Titre: "Nos actions sur le terrain"
  Image: Photo d'une activité
  Contenu: Description des activités...

Section 3 : Citation
  Contenu: Témoignage d'un partenaire
  Sous-titre: Nom du partenaire
```

### Projet "Réécriture d'ouvrages"
```
Section 1 : Texte + Image à droite
  Titre: "Le peuplement du plateau de Manika"
  Image: Couverture du livre
  Contenu: Résumé de l'ouvrage...

Section 2 : Image en haut
  Titre: "Proverbes et adages Ndembu"
  Image: Photo du manuscrit original
  Contenu: Présentation du travail...

Section 3 : Texte seul
  Titre: "Processus de réécriture"
  Contenu: Méthodologie utilisée...
```

### Projet "Soutien à la scolarité"
```
Section 1 : Image en haut
  Titre: "Les écoles partenaires"
  Image: Photo de groupe des élèves
  Contenu: Présentation des écoles...

Section 2 : Texte + Image à droite
  Titre: "Cynthia Mujinga, 8 ans"
  Sous-titre: "Rêve de devenir infirmière"
  Image: Photo de Cynthia
  Contenu: Son histoire, son parcours...

Section 3 : Texte + Image à droite
  Titre: "Julia Thumba, 10 ans"
  Sous-titre: "Aspire à devenir institutrice"
  Image: Photo de Julia
  Contenu: Son histoire...

Section 4 : Citation
  Contenu: Témoignage d'un parent
  Sous-titre: Parent d'élève

Section 5 : Texte seul
  Titre: "Impact sur les familles"
  Contenu: Statistiques et résultats...
```

## 🎯 Conseils

✅ **À faire :**
- Varier les types de mise en page pour un rendu dynamique
- Utiliser des images de qualité
- Écrire des légendes descriptives
- Alterner texte/image pour éviter la monotonie

❌ **À éviter :**
- Trop de sections texte seul d'affilée
- Images sans légende
- Sections trop longues (diviser en plusieurs sections)
